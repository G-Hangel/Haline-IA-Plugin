# Haline AI for Krita

A tool for [Krita](https://krita.org) that corrects your strokes with AI: draw a shape freehand and, when you lift the pen, it is redrawn perfectly with the brush and color you are using.

Recognized shapes:

- line
- circle
- rectangle
- triangle
- sine curve / curve
- polyline

All inference runs locally on the CPU (no GPU or internet required).

## Installation

**Requirements:** Windows 10/11 64-bit and Krita **5.3.x**.

1. Download `HalineAI-<version>-Setup.exe` from the [Releases](../../releases) page.
2. Close Krita and run the installer. It finds the Krita folder automatically.
3. Open Krita.

The installer is available in **English**, **Portuguese (Brazil)** and **Simplified Chinese**.

To uninstall, use **Settings → Apps → Installed apps → Haline AI for Krita**.

## Usage

1. In the toolbox, choose the **η** tool in the shape tools group, or press **Ctrl+Alt+H**.
2. Draw the shape freehand and lift the pen.
3. The stroke is replaced by the corrected shape.

If the shape is not recognized, the stroke stays as drawn.

**Troubleshooting:** the plugin logs what happens to `%TEMP%\haline_plugin.log`. If the AI fails to load, the messages start with `engine:`.

## How it works

Krita for Windows is built with **llvm-mingw**, and libtorch is only available for **MSVC**. The two ABIs cannot be mixed, so the plugin has two parts:

| Part | Folder | Compiler | Role |
|---|---|---|---|
| Tool | `plugin/tool_haline` | llvm-mingw (clang) | Toolbox tool; captures the stroke and paints the final shape |
| Engine | `engine` | MSVC | `haline_engine.dll`: a plain C API over libtorch that runs the TorchScript models |

The tool loads the engine at runtime (`LoadLibraryExW`), searching in this order:

1. `HALINE_ENGINE_DIR`;
2. `lib/kritaplugins/haline` next to the plugin.

The engine uses two models:

- **Cleaner** (U-Net): cleans the sketch;
- **Classifier**: identifies the shape.

The final geometric fit (line, rectangle, triangle, spline etc.) is done in the plugin.

The models in `engine/models/*_ts.pt` are generated by the training project (`export_torchscript.py`).

### Structure

```
plugin/tool_haline/   Krita tool (C++/Qt5) and η icon
engine/               AI engine (C++/libtorch) and TorchScript models
installer/            graphical installer (Inno Setup) and install.ps1 (quick test install)
build.sh              builds, packages into dist/, installs and generates the Setup
```

## Building from source

All commands run in **Git Bash** at the repository root. `build.sh` mounts the root on drive **K:** (`subst`) because paths with spaces break pkg-config and Boost, so the K: letter must be free.

### Prerequisites

- Git for Windows
- CMake ≥ 3.18
- Python 3.12+
- Visual Studio 2022 or 2026 with "Desktop development with C++"
- Krita 5.3.x installed

### 1. Tools (`tools/` folder)

```bash
mkdir -p tools && cd tools
curl -LO https://github.com/mstorsjo/llvm-mingw/releases/download/20251216/llvm-mingw-20251216-ucrt-x86_64.zip
unzip -q llvm-mingw-20251216-ucrt-x86_64.zip && rm llvm-mingw-20251216-ucrt-x86_64.zip
curl -LO https://github.com/ninja-build/ninja/releases/latest/download/ninja-win.zip
unzip -q ninja-win.zip && rm ninja-win.zip
curl -LO https://github.com/jrsoftware/issrc/releases/download/is-6_7_3/innosetup-6.7.3.exe
./innosetup-6.7.3.exe //VERYSILENT //CURRENTUSER //NOICONS "//DIR=$(cygpath -w "$PWD/innosetup")"
rm innosetup-6.7.3.exe
cd ..
```

### 2. Krita source

Tag `v6.0.3` is the same commit (`858d352`) as Krita 5.3.3; here it is built with Qt5. After cloning, register the plugin in Krita's tool tree:

```bash
git clone --depth 1 --branch v6.0.3 https://invent.kde.org/graphics/krita.git src/krita
echo 'add_subdirectory( "${CMAKE_SOURCE_DIR}/../../plugin/tool_haline" "${CMAKE_BINARY_DIR}/plugins/tools/tool_haline" )' \
    >> src/krita/plugins/tools/CMakeLists.txt
```

### 3. Krita dependencies (prebuilt by KDE CI, ~1.6 GB)

```bash
python -m venv venv
cd src/krita
git clone --depth 1 https://invent.kde.org/packaging/krita-deps-management.git
git clone --depth 1 https://invent.kde.org/packaging/krita-ci-utilities.git krita-deps-management/ci-utilities
../../venv/Scripts/pip install -r krita-deps-management/requirements.txt

export PYTHONUTF8=1
../../venv/Scripts/python -u krita-deps-management/tools/replace-branch-in-seed-file.py \
    krita-deps-management/latest/krita-deps.yml -p -o branch-corrected-deps.yml -d master
../../venv/Scripts/python -u krita-deps-management/tools/generate-deps-file.py \
    -s branch-corrected-deps.yml -o .kde-ci.yml

R="$(cd ../.. && pwd)"; W="$(cd ../.. && pwd -W)"
export PATH="$R/tools/llvm-mingw-20251216-ucrt-x86_64/bin:$R/tools:$PATH" CC=clang CXX=clang++ \
    KDECI_BUILD_TYPE=Release KDECI_GITLAB_SERVER=https://invent.kde.org/ \
    KDECI_PACKAGE_PROJECT=teams/ci-artifacts/krita-windows KDECI_CACHE_PATH="$W/deps/cache" \
    KDECI_REPO_METADATA_PATH="$W/src/krita/krita-deps-management/repo-metadata" \
    KDECI_COMPRESS_PACKAGES_ON_DOWNLOAD=False
../../venv/Scripts/python -u krita-deps-management/ci-utilities/run-ci-build.py \
    --project krita --branch master --platform Windows/Qt5/Shared --only-env -e "$W/deps/env.sh"
cd ../..
```

Dependencies are installed into `src/krita/_install`. If a download fails midway, run the last command again.

### 4. AI engine

The engine uses the libtorch shipped in the PyTorch pip package (CPU build, tested with 2.14.1):

```bash
pip install torch==2.14.1 --index-url https://download.pytorch.org/whl/cpu
```

By default CMake looks for torch in `../../Treinamento/.venv/Lib/site-packages/torch`; to use another location, pass `-DHALINE_TORCH_ROOT`:

```bash
cmake -S engine -B engine/build -G "Visual Studio 18 2026" -A x64 \
    -DHALINE_TORCH_ROOT="C:/path/to/site-packages/torch"   # VS 2022: "Visual Studio 17 2022"
cmake --build engine/build --config Release
```

The result is `engine/build/Release/haline_engine.dll`, together with the torch DLLs.

For more information, visit the AI ​​repository: https://github.com/G-Hangel/Haline-Andante

### 5. Plugin, package and installer

```bash
./build.sh           # builds the plugin and assembles dist/ (same folder layout as Krita)
./build.sh install   # installs dist/ into Krita (quick test; asks for administrator permission)
./build.sh setup     # generates release/HalineAI-<version>-Setup.exe
```

The first CMake configure takes a few minutes; subsequent runs only rebuild the plugin.

To produce a new installer version, change `AppVer` in `installer/haline.iss`.

The contents of `dist/lib/kritaplugins` can also be copied manually to `<Krita folder>/lib/kritaplugins`.
